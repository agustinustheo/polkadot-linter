# RTC002 - Pallet Missing from define_benchmarks!

> **Severity:** Warning · **Family:** runtime-config · **Engine:** source analysis (syn) · **Rule name:** `pallet-missing-from-define-benchmarks`

## Description

A runtime's `define_benchmarks!` list determines which pallets the benchmark CLI can run against this runtime. A runtime-local weights file (`weights::pallet_x::WeightInfo<Runtime>`) for a pallet that is not in the list cannot be regenerated. It keeps whatever numbers it was copied with, often from another runtime or an old SDK version, while the pallet code, its configuration, and the reference hardware change underneath it. The binding looks benchmarked, but it goes stale silently.

## What it detects

The rule applies only when the runtime crate has at least one `define_benchmarks!` invocation (any path, any file under `src/`, excluding test paths). It reports a `*WeightInfo` binding inside `impl <pallet>::Config for Runtime` when:

- the bound type is runtime-local, `weights::<module>::<Type>` or `crate::weights::<module>::<Type>`; and
- none of the following appears among the `define_benchmarks!` entries: `<module>`, any segment of the Config trait's pallet path, or the pallet path joined with `_`. Each entry contributes both its last path segment and its whole path joined with `_`, so `[polkadot_runtime_parachains::disputes::slashing, ParasSlashing]` covers `weights::polkadot_runtime_parachains_disputes_slashing`.

### Restrictions (to keep false positives low)

- Pallets bound to upstream or placeholder weights are not reported here. Those are RTC001's concern.
- A pallet counts as covered if *any* instance is benchmarked (`[pallet_assets, Pool]` covers `weights::pallet_assets_pool`). Missing benchmarks for one instance of an instanced pallet are therefore not reported.
- Runtimes without `define_benchmarks!` are not reported, because the rule cannot tell intent.

## Runtime scope

Same as all RTC rules; see [Runtime Configuration Rules](runtime-config.md).

## What should be avoided

```rust
impl pallet_sudo::Config for Runtime {
    type WeightInfo = weights::pallet_sudo::WeightInfo<Runtime>; // ❌ never regenerated
}

frame_benchmarking::define_benchmarks!(
    [pallet_balances, Balances]
    // pallet_sudo missing
);
```

## Best practice

```rust
frame_benchmarking::define_benchmarks!(
    [pallet_balances, Balances]
    [pallet_sudo, Sudo]
);
```
