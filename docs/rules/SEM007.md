# SEM007 - Deprecated RuntimeDebug Derive

> **Severity:** Warning · **Family:** semantic · **Engine:** source analysis (syn) · **Rule name:** `runtime-debug-deprecated`

## Description

`RuntimeDebug` was a FRAME-specific derive macro that behaved like `Debug` in native builds but formatted every value as `<wasm:stripped>` in the Wasm runtime. The idea was to shave debug-formatting code out of the runtime blob. In practice the space savings turned out to be negligible, while the cost was very real: whenever something went wrong on-chain or in Wasm-executed tests, logs and error messages contained no useful information about the values involved.

The Polkadot SDK has since moved away from `RuntimeDebug` in favor of the standard `Debug` derive (and `DebugNoBound` where the type's generic parameters should not receive `Debug` bounds). Keeping `RuntimeDebug` on new types means debugging runtime issues — often the moments when detail matters most — with stripped, useless output, and it ties the codebase to a deprecated API that upstream is actively removing.

For pallet authors the migration is mechanical: replace `RuntimeDebug` with `Debug`, and `RuntimeDebugNoBound` with `DebugNoBound`.

## What it detects

- A `#[derive(...)]` attribute on a struct, enum, or union that includes `RuntimeDebug` (flagged with the suggested replacement `Debug`).
- A `#[derive(...)]` attribute that includes `RuntimeDebugNoBound` (flagged with the suggested replacement `DebugNoBound`).

## What should be avoided

```rust
// ❌ deprecated derive strips debug output in Wasm builds
#[derive(Clone, Encode, Decode, PartialEq, RuntimeDebug, TypeInfo)]
pub struct Listing<Balance> {
    pub price: Balance,
    pub expiry: u32,
}
```

When this type shows up in a failed assertion or a runtime log emitted from Wasm, it prints as `<wasm:stripped>` instead of its actual field values.

## Best practice

```rust
// ✅ standard Debug keeps full formatting everywhere
#[derive(Clone, Encode, Decode, PartialEq, Debug, TypeInfo)]
pub struct Listing<Balance> {
    pub price: Balance,
    pub expiry: u32,
}
```

If the struct is generic over `T: Config` and a plain `Debug` derive would demand unwanted bounds, use FRAME's bound-free variant instead:

```rust
// ✅ Option 2: DebugNoBound for Config-generic types
#[derive(CloneNoBound, PartialEqNoBound, DebugNoBound, Encode, Decode, TypeInfo)]
#[scale_info(skip_type_params(T))]
pub struct Listing<T: Config> {
    pub price: BalanceOf<T>,
    pub expiry: BlockNumberFor<T>,
}
```
