# RTC005 - Insecure Collective-Flip Randomness in the Runtime

> **Severity:** Warning · **Family:** runtime-config · **Engine:** source analysis (syn) · **Rule name:** `insecure-randomness-in-runtime`

## Description

`pallet_insecure_randomness_collective_flip` (named `pallet_randomness_collective_flip` before it was renamed) derives its "randomness" from the hashes of the previous 81 blocks. Anyone can predict the output, and block authors can bias it by choosing whether to author or withhold a block. Every consumer wired to it inherits that weakness: contract `random()` calls, lotteries, or committee shuffling. The pallet's name says so, and it exists for testing only.

## What it detects

In non-test runtime code:

- a `construct_runtime!` entry naming `pallet_insecure_randomness_collective_flip` or `pallet_randomness_collective_flip`. Entries gated with `#[cfg(test)]` or a `runtime-benchmarks`/`try-runtime`/`test-helpers` feature are skipped;
- a type alias or associated type whose type mentions either crate name or `RandomnessCollectiveFlip`. This covers `#[runtime::pallet_index] pub type RandomnessCollectiveFlip = ...` declarations and `type Randomness = RandomnessCollectiveFlip;` bindings.

`use` items, the empty `impl pallet_insecure_randomness_collective_flip::Config for Runtime {}`, comments, and byte-string storage prefixes in removal migrations are not reported.

## Runtime scope

Same as all RTC rules; see [Runtime Configuration Rules](runtime-config.md). kitchensink (dev) wires collective flip into `pallet_contracts`, `pallet_society` and `pallet_lottery` and is reported only with `include_dev_runtimes = true`.

## What should be avoided

```rust
impl pallet_contracts::Config for Runtime {
    type Randomness = RandomnessCollectiveFlip; // ❌ predictable and biasable
}
```

## Best practice

```rust
impl pallet_contracts::Config for Runtime {
    type Randomness = pallet_babe::RandomnessFromOneEpochAgo<Runtime>;
}
```

On parachains, source randomness from relay-chain VRF output, for example via `cumulus_pallet_parachain_system::RelaychainDataProvider`, rather than from local block hashes.
