# RTC003 - XCM delivery is free

| Severity | Default | Engine | Name |
| --- | --- | --- | --- |
| warning | on | syntax | `xcm-fees-waived` |

## What it finds

The XCM `FeeManager` waives fees for every origin, or a router's delivery price
is empty. XCM delivery is then free for every sender.

## Why it matters

Delivery fees limit how many messages a sender can send. Without them, anyone
can fill the XCMP, UMP or DMP queues for the cost of one local transaction.
Other users' messages are then delayed or dropped. SR Labs rated this High in
several audits.

## Example

```rust
// Bad
impl xcm_executor::Config for XcmConfig {
    type FeeManager = WaiveDeliveryFees;
}
pub type WaivedLocations = Everything; // used in XcmFeeManagerFromComponents
impl cumulus_pallet_xcmp_queue::Config for Runtime {
    type PriceForSiblingDelivery = NoPriceForMessageDelivery<ParaId>;
}
```

```rust
// Good
pub type WaivedLocations = (
    Equals<RootLocation>,
    RelayOrOtherSystemParachains<AllSiblingSystemParachains, Runtime>,
);
impl xcm_executor::Config for XcmConfig {
    type FeeManager = XcmFeeManagerFromComponents<
        WaivedLocations,
        SendXcmFeeToAccount<Self::AssetTransactor, TreasuryAccount>,
    >;
}
pub type PriceForSiblingParachainDelivery =
    ExponentialPrice<FeeAssetId, BaseDeliveryFee, TransactionByteFee, XcmpQueue>;
```

## How to fix

1. Waive fees only for named system locations.
2. Set an `ExponentialPrice` delivery price on each router.

## How it decides

It reports these forms in the runtime crate:

- `type FeeManager = WaiveDeliveryFees;`
- `type FeeManager = XcmFeeManagerFromComponents<W, _>;`, where `W` is
  `Everything`, a tuple that contains `Everything`, or a same-file alias of one.
- `PriceForSiblingDelivery`, `PriceForParentDelivery` or
  `PriceForChildParachainDelivery` set to `()` or `NoPriceForMessageDelivery`.
- `ParentAsUmp<_, _, P>` or `ChildParachainRouter<_, _, P>`, where `P` is `()`
  or `NoPriceForMessageDelivery`.

`type FeeManager = ();` is not reported here. That form charges fees and burns
them, so [RTC006](RTC006.md) reports it.

## Limits

- It skips a `FeeManager` when the same impl sets `XcmSender = ()` and
  `MessageExporter = ()`. That executor cannot send, so it pays no fee.
- It does not resolve a `WaivedLocations` alias in another file.
- Pinned SDK: 0 findings on production runtimes. Narrow `WaivedLocations` on
  Westend are not reported.

Runtime scope: see [Runtime configuration rules](runtime-config.md).

## Configuration

No rule-specific settings. Use `[rules.enabled]` and `[rules.severity]`.
