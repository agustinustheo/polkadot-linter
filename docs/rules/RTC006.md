# RTC006 - XCM Fees Burned

> **Severity:** Warning · **Family:** runtime-config · **Engine:** source analysis (syn) · **Rule name:** `xcm-fees-burned`

## Description

The XCM executor hands every delivery and export fee it collects to its `FeeManager`. At the pinned SDK, `impl FeeManager for ()` (`polkadot/xcm/xcm-executor/src/traits/fee_manager.rs`) returns `is_waived = false` and has an empty `handle_fee`. The trait documents that doing nothing "silently burns the fees". Senders still pay, so congestion control works, but the revenue is destroyed instead of reaching the treasury, collators, or an account that offsets delivery costs.

SR Labs reported the same setting as a Critical/High "fees waived" finding in audits of runtimes built on older SDK versions (OpenZeppelin 2024-04 §3.2.1, InvArch 2024 §5.1, Peaq 2402 §5.2.3). On current SDKs the impact is economic rather than a free-messaging DoS, so this is a separate rule from [RTC003](RTC003.md), with its own lower default severity, labels, and suppression.

## What it detects

`type FeeManager = ();` inside `impl xcm_executor::Config for ...` (or any `impl ...::Config for XcmConfig`), unless the same impl sets both `type XcmSender = ();` and `type MessageExporter = ();`. Such an executor can never pay a delivery or export fee, so there is nothing to burn.

## Severity rationale

The default is **warning**. Burning XCM fees is sometimes an intended policy, and it does not make delivery free. If your runtime is pinned to an SDK version where `impl FeeManager for ()` waives fees, raise the severity to error:

```toml
[rules.severity]
"RTC006" = "error"
```

## Runtime scope

Same as all RTC rules; see [Runtime Configuration Rules](runtime-config.md).

## What should be avoided

```rust
impl xcm_executor::Config for XcmConfig {
    type XcmSender = XcmRouter;
    type FeeManager = (); // ⚠️ fees charged, then burned
}
```

## Best practice

```rust
impl xcm_executor::Config for XcmConfig {
    type FeeManager = XcmFeeManagerFromComponents<
        WaivedLocations,
        SendXcmFeeToAccount<Self::AssetTransactor, TreasuryAccount>,
    >;
}
```

## Configuration

```toml
[rules.severity]
"RTC006" = "warning"

[rules.enabled]
"RTC006" = false
```
