# RTC001 - Placeholder WeightInfo in a runtime

| Severity | Default | Engine | Name |
| --- | --- | --- | --- |
| warning | on | syntax | `placeholder-weight-info-in-runtime` |

## What it finds

An `impl <pallet>::Config for Runtime` binds a `*WeightInfo` type to `()` or to
a `TestWeightInfo` type.

## Why it matters

These weights were not measured on this runtime. `()` uses SDK reference
numbers, or zero for some pallets. `TestWeightInfo` returns zero or a flat
constant with no proof size. Calls that cost too little let an attacker fill
blocks cheaply and can push a block past its PoV limit. SR Labs reported this
as High in several audits (see References).

## Example

```rust
// Bad
impl pallet_xcm::Config for Runtime {
    type WeightInfo = pallet_xcm::TestWeightInfo;
}
impl pallet_message_queue::Config for Runtime {
    type WeightInfo = ();
}
```

```rust
// Good
impl pallet_message_queue::Config for Runtime {
    type WeightInfo = weights::pallet_message_queue::WeightInfo<Runtime>;
}
```

## How to fix

1. Add the pallet to `define_benchmarks!`.
2. Run the benchmarks on this runtime.
3. Bind the generated weights file.

## Limits

- It skips pallets in `unit_weight_info_allowlist`. `pallet_babe`,
  `pallet_grandpa` and `pallet_beefy` are in the list, because their `()`
  weights are hand-written production weights.
- It skips `type WeightInfo = ();` for a pallet with no calls (for example
  `pallet_mmr`). The pallet must be a `path` dependency of the runtime.
  Registry and git dependencies are still reported. `TestWeightInfo` is always
  reported.
- It skips runtimes with a `rococo` or `glutton` name token (Parity test
  networks). Only RTC001 skips them.
- Pinned SDK: 14 findings on templates and Westend system chains, all correct.

Runtime scope: see [Runtime configuration rules](runtime-config.md).

## Configuration

```toml
[runtime_config]
unit_weight_info_allowlist = ["pallet_babe", "pallet_beefy", "pallet_grandpa"]
flag_substrate_weight = false        # true also reports upstream SubstrateWeight<Runtime>
substrate_weight_severity = "advisory"
```

`flag_substrate_weight` is off by default. The pinned SDK has 13 production
bindings of `SubstrateWeight`, and some are deliberate. A
`[rules.severity]` entry for RTC001 applies to both forms.
