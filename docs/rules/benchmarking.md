# Benchmarking Rules (BEN)

Benchmarking rules ensure that every weight a runtime charges is backed by a measured benchmark, and that benchmarks actually verify the effect of what they measure.

| Rule | Title | Default severity | Engine |
| --- | --- | --- | --- |
| [`BEN001`](BEN001.md) | Weight Function Without a Corresponding Benchmark | Warning | source (syn) |
| [`BEN002`](BEN002.md) | Benchmark Without Verification Block | Warning | source (syn) |
| [`BEN003`](BEN003.md) | Extrinsic Without a Benchmark | Warning | source (syn) |
