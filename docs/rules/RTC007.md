# RTC007 - XCM Deny Barrier Not Applied to Nested Programs

> **Severity:** Warning · **Family:** runtime-config · **Engine:** source analysis (syn) · **Rule name:** `xcm-deny-barrier-not-recursive`

## Description

`DenyThenTry<Deny, Allow>` runs its `Deny` barrier over the top-level instructions of an incoming message only. Instructions that carry an inner XCM program (`SetAppendix`, `SetErrorHandler`, `ExecuteWithOrigin`) execute that program locally, and the executor does not run the barrier on it again. A deny that inspects instructions, such as `DenyReserveTransferToRelayChain`, is therefore bypassed by putting the denied instruction inside one of them ([polkadot-sdk #7148](https://github.com/paritytech/polkadot-sdk/issues/7148)).

[polkadot-sdk #7200](https://github.com/paritytech/polkadot-sdk/pull/7200) added `DenyRecursively<Inner>` (`polkadot/xcm/xcm-builder/src/barriers.rs`), which applies `Inner` to the top-level message and to every nested program, and wrapped the deny of every SDK system runtime in it.

## What it detects

In production runtime code, a `DenyThenTry<D, _>` whose deny `D` (or an element of a tuple `D`, following `type` aliases in the same file) is an instruction-inspecting deny that is not wrapped in `DenyRecursively<..>`:

- `DenyReserveTransferToRelayChain` (xcm-builder);
- `DenyExportMessageFrom` (`cumulus/parachains/runtimes/bridge-hubs/common/src/barriers.rs`).

Other denies, including runtime-local ones, are not reported. Denies that never look at the instructions (for example the relay chains' `DenyOnceMigrationStarts`) cannot be bypassed by nesting.

## Runtime scope

Same as all RTC rules; see [Runtime Configuration Rules](runtime-config.md). The SDK's `yet-another-parachain-runtime` and `pallet-staking-async-parachain-runtime` (dev runtimes) still use a plain `DenyReserveTransferToRelayChain` and are reported only with `include_dev_runtimes = true`.

## What should be avoided

```rust
pub type Barrier = TrailingSetTopicAsId<
    DenyThenTry<
        DenyReserveTransferToRelayChain, // ⚠️ bypassed by SetAppendix(Xcm(vec![InitiateReserveWithdraw { .. }]))
        (TakeWeightCredit, AllowTopLevelPaidExecutionFrom<Everything>),
    >,
>;
```

## Best practice

```rust
pub type Barrier = TrailingSetTopicAsId<
    DenyThenTry<
        DenyRecursively<DenyReserveTransferToRelayChain>,
        (TakeWeightCredit, AllowTopLevelPaidExecutionFrom<Everything>),
    >,
>;
```
