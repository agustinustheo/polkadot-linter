# SEM011 - Weight::zero() Placeholder in Weight Attributes

> **Severity:** Warning · **Family:** semantic · **Engine:** source analysis (syn) · **Rule name:** `weight-zero-placeholder`

## Description

Every dispatchable declares a weight that tells block production how much of the block's resources the call will consume, and fees are charged based on it. `#[pallet::weight(Weight::zero())]` declares the extrinsic to be completely free: zero ref-time, zero proof size, and (weight-wise) zero fee contribution.

That is almost never true. Even the most trivial dispatchable verifies its origin and executes some logic, and anything that touches storage consumes both weight dimensions. A zero-weight extrinsic is a standing invitation for spam: an attacker can submit unlimited copies at negligible cost, and because the block builder believes each one is free, it will pack blocks far past their real capacity. The result is blocks that take too long to execute or exceed the PoV limit — degraded block times or a stalled parachain, at attacker-chosen moments.

`Weight::zero()` typically enters a codebase as a "fix it later" placeholder during prototyping. This rule exists to make sure it does not survive into production: before deployment every dispatchable should carry a weight generated by FRAME benchmarking, which measures real execution cost and proof-size impact rather than guessing.

## What it detects

- A `#[pallet::weight(...)]` or `#[pallet::weight_of_authorize(...)]` attribute on a function whose expression is a call to `Weight::zero()` (any path ending in `Weight` with the `zero` function, e.g. `Weight::zero()` or `frame_support::weights::Weight::zero()`).
- Test files are excluded.

## What should be avoided

```rust
#[pallet::call_index(0)]
// ❌ declares the call free — the chain will accept unlimited copies
#[pallet::weight(Weight::zero())]
pub fn register(origin: OriginFor<T>, name: BoundedVec<u8, T::MaxNameLen>) -> DispatchResult {
    let who = ensure_signed(origin)?;
    ensure!(!Registry::<T>::contains_key(&who), Error::<T>::AlreadyRegistered);
    Registry::<T>::insert(&who, name);
    Ok(())
}
```

The call performs a storage read and a write yet advertises zero cost, so its real resource use is invisible to block building and effectively unpriced for attackers.

## Best practice

```rust
// benchmarking.rs — measure the real cost
#[benchmark]
fn register() {
    let caller: T::AccountId = whitelisted_caller();
    let name = BoundedVec::try_from(vec![b'x'; T::MaxNameLen::get() as usize]).unwrap();

    #[extrinsic_call]
    _(RawOrigin::Signed(caller), name);
}
```

```rust
// lib.rs — ✅ use the generated WeightInfo function
#[pallet::call_index(0)]
#[pallet::weight(T::WeightInfo::register())]
pub fn register(origin: OriginFor<T>, name: BoundedVec<u8, T::MaxNameLen>) -> DispatchResult {
    // ...
    Ok(())
}
```

Run the benchmarks against reference hardware and wire the generated `weights.rs` into the pallet through the `WeightInfo` associated type; the declared weight then tracks the measured worst case in both dimensions.
