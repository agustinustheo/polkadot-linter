# RTC010 - Storage-Reading Aliaser on the Unpaid-Execution Barrier

> **Severity:** Warning · **Family:** runtime-config · **Engine:** source analysis (syn) · **Rule name:** `storage-reading-unpaid-aliaser`

## Description

`AllowExplicitUnpaidExecutionFrom<T, Aliasers>` emulates the origin-altering instructions that come before `UnpaidExecution`. It calls `Aliasers::contains` for every `AliasOrigin` it meets, up to 5 per message. Barriers run before any fee is taken. `pallet_xcm::AuthorizedAliasers` reads the `AuthorizedAliases` storage on keys the message chooses, so passing it here lets any incoming message trigger several unmetered storage reads and then be rejected without paying.

polkadot-sdk [#12831](https://github.com/paritytech/polkadot-sdk/pull/12831) changed the barrier's documentation, which used to say to reuse `xcm_executor::Config::Aliasers`. It now says to pass only a cheap, computation-only subset. polkadot-fellows/runtimes [#1237](https://github.com/polkadot-fellows/runtimes/pull/1237) (runtimes 2.4.0) fixed the 11 system parachains that passed `TrustedAliasers`, which includes `AuthorizedAliasers<Runtime>`.

## What it detects

`AllowExplicitUnpaidExecutionFrom<_, A>` anywhere in a production runtime file, where `A` is `AuthorizedAliasers<..>` or a tuple that contains it. Same-file `type` aliases are resolved, including nested ones (`(CheapTrustedAliasers, AuthorizedAliasers<Runtime>)` behind `TrustedAliasers`). The executor's own `type Aliasers = TrustedAliasers;` is not reported, because the executor runs after fees are paid.

Only `AuthorizedAliasers` is recognised as storage-reading. A custom `ContainsPair` that reads storage is not detected.

## Runtime scope

Same as all RTC rules; see [Runtime Configuration Rules](runtime-config.md).

## What should be avoided

```rust
pub type TrustedAliasers = (AliasChildLocation, AuthorizedAliasers<Runtime>);

AllowExplicitUnpaidExecutionFrom<(ParentOrParentsPlurality, FellowshipEntities), TrustedAliasers>,
```

## Best practice

```rust
/// Computation-only: evaluated by the barrier before any fee is charged.
pub type CheapTrustedAliasers = (AliasChildLocation,);
/// Executor aliasers: may read storage.
pub type TrustedAliasers = (CheapTrustedAliasers, AuthorizedAliasers<Runtime>);

AllowExplicitUnpaidExecutionFrom<(ParentOrParentsPlurality, FellowshipEntities), CheapTrustedAliasers>,
```
